Baixe o ZIP do tipo de disco que você vai assistir (**BD** para Blu-ray, **UHD** para 4K UHD) e do seu sistema. Cada tipo de disco usa um pendrive próprio. Cada ZIP já traz o programa, a pasta `pacote` e um `LEIA-ME.txt` com os passos.

| Sistema | Qual baixar |
|---|---|
| Windows 10 ou 11 | `…-Windows.zip` |
| Mac com chip Apple (M1 em diante) | `…-macOS-AppleSilicon.zip` |
| Mac com processador Intel | `…-macOS-Intel.zip` |
| Linux | `…-Linux.zip` |

Para Panasonic DP-UB450, DP-UB150 e DP-UB154 vendidos nos EUA, com firmware 1.13. Guia completo: https://michaelfdias.github.io/subdrive/
